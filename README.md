# מתכנן הטיול

אפליקציית ווב בעברית לתכנון ימי טיול ומעקב אחרי תקציב.

- **ימים:** לוח זמנים לכל יום, פעילויות עם עלות משוערת וסימון "בוצע".
- **תכנון תקציב:** תקציב כולל וחלוקה לקטגוריות.
- **הוצאות:** רישום הוצאות, חיפוש, סינון ומיון, ושיוך הוצאה ליום.
- **ניתוח:** מתוכנן מול בפועל, הוצאה יומית ותובנות.
- ייצוא לגיבוי (JSON) ולאקסל (CSV), ייבוא מגיבוי, ובחירת מטבע (₪ $ € £).

הנתונים נשמרים רק בדפדפן (localStorage). אין שרת ואין חשבון משתמש.

## הרצה

```bash
npm install
npm run dev
```

ואז לפתוח את http://localhost:5173

בנייה לפרודקשן: `npm run build`, והפלט נוצר בתיקייה `dist/`.

## טכנולוגיות

React 19, TypeScript, Vite, Tailwind CSS 4 ו-lucide-react.
